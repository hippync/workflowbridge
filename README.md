# WorkflowBridge

> Self-hosted webhook bridge: Stripe payments to Notion records and Slack notifications in 5 minutes.

🚧 **Active development — kickoff May 25, 2026.** First release expected mid-June 2026.

## What this will do

A minimal, self-hosted alternative to Zapier's "Stripe → Notion + Slack" workflow. Deploy to Vercel in 5 minutes, own your code forever, no monthly subscription.

Target user: solo founders, coaches, and small agencies running Stripe + Notion + Slack who want automation without recurring SaaS fees.

## Stack

Next.js 14 · TypeScript · Vercel KV · Zod · Vitest · Deployed on Vercel
